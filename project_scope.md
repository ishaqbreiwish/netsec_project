Project Goal/Scope
The goal of the course project is for you to get your hands dirty with some real network security/privacy. Through the project, you should demonstrate that you explored something involving networking and security/privacy in depth, whether it's

evaluating how real-world systems implement or handle some aspect of network security
developing new attacks
creating new defenses
developing tools to assist with any of the above tasks
something else...
What you produce through the project should including some aspect that is novel/previously unknown, where I shouldn't just be able to find a few papers, articles, blog posts, etc. that have the same content as your project output. In other words, you should not just be aggregating information from other references, but going out and looking at real network security/privacy yourself. That doesn't mean you can't build off or replicate similar methods as prior work, but if so, your project should provide up-to-date results (the "new" factor) and a comparison with the prior work. This project proposal is to help you scope out your project more concretely.
